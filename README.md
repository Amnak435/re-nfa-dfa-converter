# RE → NFA → DFA Converter & Simulator

A complete implementation of the Regular Expression to NFA to DFA 
conversion pipeline, built in Python.

## Features
- Converts any Regular Expression to NFA using Thompson's Construction
- Converts NFA to DFA using Subset Construction Algorithm
- Professional dark-themed Tkinter GUI
- NFA and DFA transition tables
- Graphviz state diagram visualization
- String simulator with Accept/Reject output
- Batch testing with pre-defined test cases

## Algorithms Used
- Shunting-Yard Algorithm (Regex to Postfix)
- Thompson's Construction (RE to NFA)
- Subset Construction / Powerset Algorithm (NFA to DFA)

## How to Run
- pip install Pillow
- python main.py

## Tech Stack
- Python 3.10+
- Tkinter (GUI)
- Graphviz (Diagrams)
